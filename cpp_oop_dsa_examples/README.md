# C++ OOP & DSA Examples

This folder contains C++ code examples demonstrating Object-Oriented Programming (OOP) concepts and Data Structures & Algorithms (DSA) tips and tricks.

## Folder Structure

- `oop_examples/` - Object-Oriented Programming examples
- `dsa_examples/` - Data Structures and Algorithms examples

## OOP Examples

1. **classes_and_objects.cpp** - Basic class definition, constructors, destructors
2. **inheritance.cpp** - Single and multiple inheritance, virtual functions
3. **polymorphism.cpp** - Function overloading, operator overloading, virtual functions
4. **encapsulation.cpp** - Access specifiers, getters/setters, data hiding
5. **abstraction.cpp** - Abstract classes, interfaces, pure virtual functions

## DSA Examples

1. **arrays_and_vectors.cpp** - Dynamic arrays, vector operations, common pitfalls
2. **linked_lists.cpp** - Singly/doubly linked lists, insertion/deletion algorithms
3. **stacks_and_queues.cpp** - Stack/queue implementations, applications
4. **trees.cpp** - Binary trees, BST operations, traversals
5. **graphs.cpp** - Graph representations, BFS/DFS algorithms
6. **sorting_algorithms.cpp** - Quick sort, merge sort, heap sort implementations
7. **searching_algorithms.cpp** - Binary search, hash tables, search optimizations

## Tips & Tricks

Each file includes comments explaining:
- Best practices
- Common mistakes to avoid
- Performance considerations
- Memory management tips
- C++11/14/17 features usage

## Compilation

Compile individual files with:
```
g++ -std=c++17 filename.cpp -o executable
```

Run with:
```
./executable
```

## Learning Path

Start with OOP basics, then move to DSA fundamentals. Each example builds on previous concepts.
